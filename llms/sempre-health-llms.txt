# Sempre Health

> Sempre Health is a San Francisco based digital health company, founded in 2015, that operates a
> behavior-based dynamic pricing platform for prescription medications. It works with health plans,
> pharmacy benefit managers and pharmaceutical manufacturers to adjust an enrolled member's copay at
> the point of fill: the more consistently the member refills on time, the deeper the discount.
> Outreach is by SMS. The company reports 19+ payer and PBM partners covering roughly 60% of
> commercially insured lives in the United States, coverage at retail pharmacies in all 50 states,
> a 95+ NPS, and HITRUST certification with a signed HIPAA BAA per plan.

## API status

**Sempre Health publishes no public API.** As of 2026-08-26 there is no developer portal, no API
reference, no OpenAPI/AsyncAPI/GraphQL/gRPC/SOAP contract, no MCP server, no A2A agent card, no
client SDK, and no published rate limits or API pricing. Sempre's own health-plans page describes
payer integration as the plan sharing "a list of eligible members" — a data exchange under contract,
not a developer-facing API.

This file is GENERATED by API Evangelist from the public Sempre Health surface. It is not published
by Sempre Health and does not describe an API, because there is none to describe.

## What was checked

- `www.semprehealth.com` — WordPress corporate site. `/openapi.json`, `/swagger.json`, `/api-docs`,
  `/redoc`, `/graphql`, `/llms.txt`, `/developers`, `/api`, `/docs`, `/integrations`, `/partners`,
  `/apis.json`, `/asyncapi.yaml` and every `/.well-known/` path: HTTP 404.
- `eligibility.semprehealth.com` — member eligibility single-page app. Answers HTTP 200 with the same
  453-byte HTML shell for every path including ones that cannot exist, so no 200 on this host is
  evidence of a document. Its own bundle calls one same-origin app route, `/api/eligibility.json`,
  which itself returns the HTML shell to an unauthenticated caller.
- `enroll.semprehealth.com` — member enrollment single-page app. HTTP 404 on every probed path.
- `docs.semprehealth.com` — resolves to Netlify; returned HTTP 429 with an empty body on every
  request from two separate networks. Nothing on this host could be read, and it is not indexed by
  search engines.
- `trust.semprehealth.com` — live Vanta trust center (HTTP 200). Its document list loads from a
  signed GraphQL endpoint that rejects anonymous reads.
- `github.com/semprehealth` — 7 public repositories, all forks of unrelated open-source projects or
  small internal utilities. No SDK, spec, or API tooling.
- npm and PyPI — no first-party package.
